The user-reported 1.172 screenshots showed relative text replacing prayer clocks, sparse tall cards, and Kiswah band/lettering that did not match the approved board.

## Corrections
- Keep each exact clock time and suffix prominent in landscape. Relative mode adds relative text below the clock instead of replacing it. The preference and tap interaction remain functional.
- Tighten the card composition and scale wide-phone labels, clocks and Arabic labels against the reference. Preserve responsive short-phone sizing and 48dp targets.
- Add the original unmodified Layla Thuluth font for Kiswah calligraphy and hero, with the complete embedded SIL OFL license, author attribution and FONTLOG.
- Replace detached diamond rails with continuous braided gold cord and interwoven palmette/arabesque end cartouches.
- Quiet the Kiswah cloth folds and the Miqaat left background behind live text.
- Retain stacked hero composition on the reported 891x411 English phone; small screens can use the paired arrangement.
- Retain all six distinct Gallery illustrations, native content and actions, and pinned timeline/footer.

## Stronger evidence
- Reproduce Beijing 14:35 and 17:27, long location, 36dp left cutout and 12dp bottom inset.
- Assert primary clocks and relative details separately, one-line clock suffixes, fully visible footer/timeline, readable hero, full 48dp details target and stacked name-above-clock geometry on that phone.
- Retain theme, navigation, dialog, preference, Urdu, short-screen, portrait/tablet and content regression checks.
- Native renders are inspected independently of pass/fail status. Initial iterations caught both actual sizing faults and a layout switch that fit tests alone did not detect.
- The publication workflow waits for complete validation, verifies exact source/run, signing certificate, APK checksum and zero test failures, then creates an explicitly nonproduction prerelease. It attaches twelve native screenshots and a direct approved-versus-native comparison.

The approved board is retained as docs/landscape-parity/approved-landscape-board.jpg.

Native Robolectric SDK34 testing is not physical-device acceptance. Numerical 9.9/10 fidelity and pixel identity are not certified; native typography, artwork and semantic preference states must be assessed visually. The published comparison uses the reference time for a fair comparison; the actual phone captures additionally reproduce relative mode and current Maghrib state.
