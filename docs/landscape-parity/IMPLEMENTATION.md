# Approved landscape composition fidelity

The approval board supplied as 1000166877.png is the visual reference. The previous 1.169 landscape implementation used a roomy two-line header, vertically split prayer labels and clocks, full-width hero button, oversized footer pills, Quiet artwork framing, and a plain Kiswah band. Passing fit/action tests did not verify this visual relationship to the approved board.

This revision implements the inline date/Hijri/NOW header, a 62:38 prayer-grid/hero split, names and serif clocks on the same line, clock and information icons, compact NOW/NEXT capsules, centered narrow hero details action, and shallow three-action footer pills with independent 48dp targets. The warning pill opens the complete action menu so reliability, travel, location, seasonal, update and other contextual actions remain available. Portrait and tablet layouts retain their implementation.

Kiswah uses full native Amiri Arabic with 12dp normal or 6dp short-phone vertical clearance, double stitched rails and interlaced gold end medallions. Its Home hero uses flowing Amiri instead of angular Kufi. The existing Quiet/Iqamah band remains unchanged. Home scene framing is independent of Quiet: Miqaat places the arch around the right hero; Celestial uses a dedicated reference-derived star field and mountain-lake sunset; Kiswah limits the silk embroidery to the right edge. Display & Art miniatures automatically use the updated native Home renderer.

Artwork: home_celestial_landscape_parity.png was created using the built-in image-generation tool, with the approved board as style/composition reference. Prompt: recreate only the Celestial background, wide 2.4:1, deep navy stars and lavender Milky Way at right-center, alpine peach sunset at x63% y65%, reflective lake and evergreen shore, darker left60%, no UI/text/icons/cards. All prayer content and controls remain native.

Verification includes explicit approved-composition geometry plus normal/short/cutout native renders in English/Urdu; retained phone portrait, tablet, Home/Iqamah/Quiet and action checks; full regression and lint; signed release with the established certificate. Exact 99.99% pixel identity is not claimed: the reference is generated raster artwork, while live text, dates, device proportions, insets and Arabic shaping vary. The native comparison boards are the review evidence.
